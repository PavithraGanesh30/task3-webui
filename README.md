# Task 3 – Web UI Frontend (React + TypeScript + Ant Design)

This project is a simple **React 19 + TypeScript + Ant Design** application for managing
✨ Features

Create a new task (ID, Name, Owner, Command).

View all tasks in a clean table layout.

Search tasks by name.

Delete a task.

Run a task and view its command output in the table.

Accessible and responsive UI using Ant Design components.
Clone this repository:
git clone <your_repo_url>
cd task3-webui
Install dependencies:
npm install
Start the development server:
npm start
Open in browser:
http://localhost:3000
